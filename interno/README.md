# interno/ — USO EXCLUSIVO DEL EQUIPO

> **Nada de esta carpeta se presenta, se exporta ni se cita** en el avance, en la
> exposición final, en el informe ni en las diapositivas.

El material formal y presentable está en `README.md`, `docs/` y las `GUIA.md` de cada
módulo. Esta carpeta guarda únicamente material de trabajo del equipo:

| Archivo | Contenido |
|---|---|
| `BITACORA.md` | Estado vivo del proyecto: qué se hizo, decisiones, pendientes y siguiente paso. Se actualiza en cada sesión de trabajo. |
| `REGISTRO_IA.md` | Quién usó IA, en qué parte y cómo se verificó el resultado. |
| `prompts/<modulo>.md` | Material de apoyo de desarrollo de cada módulo: desarrollo, autovalidación y estudio. |
| `prompts/revision_pr.md` | Apoyo para revisar pull requests. |

Reglas:

1. Ningún archivo de `docs/`, ninguna `GUIA.md` ni el `README.md` raíz enlaza a esta carpeta.
2. Al exportar documentos (Word/PDF) se parte solo de `docs/`.
3. Si algo de aquí debe volverse formal, se reescribe en `docs/` con tono académico; no se copia.
