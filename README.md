# TranSim754

Procesador con transistores simulados: una FPU IEEE 754 (binary32) y una ALU entera
construidas desde transistores nMOS/pMOS sobre un simulador switch-level escrito en Python.

Proyecto del curso Arquitectura de Computadoras y Sistemas Operativos (SI421U),
UNI-FIIS, 2026-II.

> Repositorio en construcción. La documentación completa se incorpora en `docs/`.

## Instalación rápida

```bash
make install
make test
```

Requiere Python 3.12 y `make`.
